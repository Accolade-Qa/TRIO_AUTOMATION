# Standalone Trio Automation Project (`TRIO_AUTOMATION`)

Independent Playwright + pytest automation framework for the Trio platform.

## Overview
- Self-contained configuration, fixtures, pages, APIs, tests, and test data.
- Isolated test execution targeting the Trio QA environment.

## Running Tests
```bash
# Run all tests in TRIO_AUTOMATION
pytest

# Run smoke test suite
pytest -m smoke

# Run regression test suite
pytest -m regression
```
